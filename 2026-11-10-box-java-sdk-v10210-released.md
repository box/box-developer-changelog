# Box Java SDK `v10.21.0` released

### New Features and Enhancements

* add `DocumentSplitManager` and document split APIs + OTP for shared links (box/box-openapi[#621][1]) ([`e7a110e`][2])
* add `metadata_template` support and `filter_fields` to legal hold assignments (box/box-openapi[#625][3]) ([`e563e7c`][4])
* add `ShuttleManager`, shuttle schemas, endpoints, and docs (box/box-openapi[#622][5]) ([`c17ead1`][6])
* add `verification_method` one-of union for signers and templates (box/box-openapi[#626][7]) ([`ffb2605`][8])
