# Box Python SDK `v4.20.0` released

### New Features and Enhancements

* **boxsdkgen:** add `DocumentSplitManager` and document split schemas/docs; support shared link OTP fields (box/box-openapi[#621][1]) ([`de4d6f6`][2])
* **boxsdkgen:** add `metadata_template` support and `filter_fields` to legal hold assignments (box/box-openapi[#625][3]) ([`73d3ba4`][4])
* **boxsdkgen:** add `ShuttleManager` and generate shuttle API models/docs (box/box-openapi[#622][5]) ([#1636][6]) ([`89a3d8a`][7])
* **boxsdkgen:** add `verification_method` field to Sign Request signer schemas (box/box-openapi[#626][8]) ([`ec11691`][9])
