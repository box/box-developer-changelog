# Box Java SDK `v5.20.0` released

### New Features and Enhancements

* **boxsdkgen:** add `DocumentSplitManager` and document split APIs/docs (box/box-openapi[#621][1]) ([`98de64e`][2])
* **boxsdkgen:** add `metadata_template` target and `filter_fields` to legal hold assignments (box/box-openapi[#625][3]) ([`cc979c2`][4])
* **boxsdkgen:** add `ShuttleManager` and generate shuttle API models/docs (box/box-openapi[#622][5]) ([`159e0ed`][6])
* **boxsdkgen:** add `verification_method` one-of type to signer schemas (box/box-openapi[#626][7]) ([`f8e2be7`][8])
