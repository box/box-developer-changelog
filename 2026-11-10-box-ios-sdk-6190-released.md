# Box iOS SDK `6.19.0` released

### New Features and Enhancements

* **boxsdkgen:** add `DocumentSplit` manager and V2026R0 schemas & one-time passcode fields (box/box-openapi[#621][1]) ([`3ce0c92`][2])
* **boxsdkgen:** add `metadata_template` assign target and `filter_fields` to legal hold APIs (box/box-openapi[#625][3]) ([`57bf7d9`][4])
* **boxsdkgen:** add `ShuttleManager` and generate shuttle API models/docs (box/box-openapi[#622][5]) ([#1711][6]) ([`35d85a4`][7])
* **boxsdkgen:** add `verification_method` field to Signer schemas for BoxSign (box/box-openapi[#626][8]) ([`cd71e8b`][9])
