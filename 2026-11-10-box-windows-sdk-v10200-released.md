# Box Windows SDK `v10.20.0` released

### New Features and Enhancements

* add `DocumentSplitManager` and document split APIs + OTP for shared links (box/box-openapi[#621][1]) ([`401ef4f`][2])
* Add `metadata_template` support and `filter_fields` to legal holds (box/box-openapi[#625][3]) ([`26578fa`][4])
* add `Shuttle` manager and `V2026R0` shuttle APIs and models (box/box-openapi[#622][5]) ([`7f4fd64`][6])
* add `verification_method` union types for Signer in BoxSign schemas (box/box-openapi[#626][7]) ([`b5a216e`][8])
* update chunked upload to support `sha512` and add `external_id` to DocGen (box/box-openapi[#620][9]) ([`0f2ba4d`][10])
