# Box iOS SDK `10.19.0` released

### New Features and Enhancements

* add `DocumentSplit` manager and `one_time_passcode` shared link OTP fields (box/box-openapi[#623][1]) ([`31eb9a0`][2])
* add `DocumentSplitManager` and document split APIs + OTP for shared links (box/box-openapi[#621][3]) ([`e75afd2`][4])
* add `filter_fields` and `metadata_template` support to legal holds API (box/box-openapi[#625][5]) ([`f635166`][6])
* add `ShuttleManager` and V2026R0 `Shuttle` schemas and endpoints (box/box-openapi[#622][7]) ([#1716][8]) ([`c32c0ed`][9])
* add `verification_method` schemas for BoxSign signers (box/box-openapi[#626][10]) ([`f3e704e`][11])
