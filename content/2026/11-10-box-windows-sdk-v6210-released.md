# Box Windows SDK `v6.21.0` released

### **New Features and Enhancements:**

* **boxsdkgen:** add `DocumentSplit` manager and one-time passcode fields for shared links (box/box-openapi[#621][1]) ([`660db37`][2])
* **boxsdkgen:** add `metadata_template` assign type and `filter_fields` to legal hold assignments (box/box-openapi[#625][3]) ([`1171a34`][4])
* **boxsdkgen:** add `ShuttleManager` and generate shuttle API models/docs (box/box-openapi[#622][5]) ([`00c2f8e`][6])
* **boxsdkgen:** add `verification_method` union types for Signer in BoxSign schemas (box/box-openapi[#626][7]) ([`75fb623`][8])
