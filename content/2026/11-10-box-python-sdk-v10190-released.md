# Box Python SDK `v10.19.0` released

### New Features and Enhancements

* add `DocumentSplitManager` and document split APIs + OTP for shared links (box/box-openapi[#621][1]) ([`98b77e6`][2])
* add `metadata_template` support and `filter_fields` to legal hold assignments (box/box-openapi[#625][3]) ([`758e56f`][4])
* add `ShuttleManager` and `shuttle_*` APIs for Shuttle `v2026` `r0` (box/box-openapi[#622][5]) ([`a52c426`][6])
* add `verification_method` field to Sign Request signer schemas (box/box-openapi[#626][7]) ([`438e678`][8])
