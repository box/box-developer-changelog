# Box Node SDK `v4.19.0` released

### New Features and Enhancements

* **boxsdkgen:** add `DocumentSplitManager` and `document_splits` SDK APIs (box/box-openapi[#621][1]) ([`783d258`][2])
* **boxsdkgen:** add `metadata_template` assign target and `filterFields` support to legal hold assignments (box/box-openapi[#625][3]) ([`646f895`][4])
* **boxsdkgen:** add `ShuttleManager` and generate shuttle API models/docs (box/box-openapi[#622][5]) ([`2d317ea`][6])
* **boxsdkgen:** add `verificationMethod` union to BoxSign signer schemas (box/box-openapi[#626][7]) ([`04713d4`][8])
