# Box Node SDK `v4.15.0` released

### Bug Fixes

* **boxsdkgen:** Fix type declarations that break `tsc` under `Node-only` `tsconfig` (box/box-codegen[#983][1]) ([#1600][2]) ([`73b5b87`][3])
* **boxsdkgen:** stop double-JSON-encoding error fields in Box API errors (box/box-codegen[#985][4]) ([#1609][5]) ([`61970fc`][6])

### New Features and Enhancements

* **boxsdkgen:** add Japanese ZIP code validation to sign request (box/box-openapi[#615][7]) ([#1597][8]) ([`195b856`][9])
* **boxsdkgen:** Support chunk upload session plan API (box/box-openapi[#616][10]) ([#1599][11]) ([`80f8130`][12])
